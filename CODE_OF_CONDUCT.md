# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience
for everyone, regardless of age, body size, disability, ethnicity, sex
characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race,
religion, or sexual identity and orientation.

## Our standards

Positive behavior includes empathy, constructive feedback, respect for
different viewpoints, responsibility for mistakes, and focus on what is best
for the community. Unacceptable behavior includes harassment, sexualized
language or attention, insults, trolling, publishing private information, and
other conduct inappropriate in a professional setting.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, issues,
and other contributions that violate this Code of Conduct. Instances of abuse
may be reported privately through the repository owner's GitHub profile.
Maintainers will respect the privacy and security of reporters.

## Scope

This Code applies in project spaces and when an individual publicly represents
the project or its community.
